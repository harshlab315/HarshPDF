ABOUT KAAGAZPRO

Built to make everyday document tasks simpler.

KaagazPro is a collection of useful tools for everyday document and image work — resizing photos for forms, compressing images, converting PDFs, and handling small tasks that otherwise take too many websites.

The Founder

Harsh Pandey FOUNDER & CREATOR

Hi, I'm Harsh, the person behind KaagazPro. I started building KaagazPro because I wanted to create something genuinely useful while learning how websites and software are built.

It's an independent project I'm building and maintaining myself — from design to testing to fixing issues. My focus is on useful tools, simple design, and reliability.

Our Story

It started with a practical problem I kept noticing. Whenever I or someone around me needed to do a small document task — like getting a photo to exactly 20KB or 50KB for a form, converting a JPG to PDF, or merging two PDFs — we had to search for a different website each time. Some sites were full of ads, some asked to upload files, and some just didn’t work well on mobile.

I thought, why not bring these everyday tools together in one simple website? That’s how KaagazPro started. I didn’t start it as a big company idea. I started building it because I wanted to create something genuinely useful while learning how websites are actually built. One tool at a time.

KaagazPro is still growing. Some tools run completely in the browser, some need more work to get right. I test them myself, fix what breaks, and try to make the mobile experience a little better each time.

Why I built KaagazPro

🧩
Everyday tasks are scattered

People need small tools for forms, photos, PDFs — but every task is on a different site.

⚡
I wanted one simple place

One place where you can find a tool, use it quickly, and download without extra steps.

🔒
Privacy matters

Where possible, files are processed directly in your browser instead of being uploaded to a server.

Building KaagazPro

KaagazPro is being built step by step. Most of the work is testing a tool with real files, finding where it breaks, fixing bugs, improving how it looks on mobile, and checking if the result actually preserves quality.

I'm learning web development through this project itself. So every improvement comes from actually building and using the product. It's still a work in progress, and that's how I want to keep building it.

What matters to me

🔵 Useful

Every tool should solve a real problem. If it doesn’t help with a form or document, it doesn’t need to be there.

🟢 Simple

People should not need technical knowledge. Upload, click, download — that’s how it should feel.

🟡 Privacy-conscious

When browser processing is possible, I prefer keeping files on the user’s device.

🟣 Continuous improvement

KaagazPro is still growing, and every improvement starts with making existing tools better.
